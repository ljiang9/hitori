# hitori · 独数

终端里的独数（Hitori）小玩具：生成谜题、回溯求解。纯标准库。

## 规则

把格子涂黑（`[x]`），满足三条：

1. **同行同列去重**：同一行 / 同一列里，未涂黑的数字不能重复；
2. **黑格不相邻**：涂黑的格子上下左右不能挨着；
3. **白格连成一片**：所有未涂黑的格子四连通。

## 用法

```bash
python -m hitori                  # 生成一道 5x5
python -m hitori --size 4         # 4x4
python -m hitori --seed 42        # 可复现
python -m hitori --solution       # 连答案一起打印
python -m hitori --solve 谜题.txt  # 求解文件里的谜题（或 --solve - 从 stdin 读）
python -m hitori --selftest       # 内置自检
```

谜题文件格式：每行 n 个 1..n 的数字，空格分隔。

## 设计取舍

- **生成思路**：随机拉丁方阵 → 随机改约 35% 格子制造重复 → 回溯求解器找出一组涂黑方案。构造上**保证可解**（生成器自己的解即为一解）。
- **求解器**：行优先回溯，涂黑判邻格、未涂黑判行列重复，附带廉价的连通性剪枝（孤立白格直接剪掉），节点预算默认 200 万。
- 尝试顺序可打乱（`order_seed`），生成多样性更好。

手工 4x4 的答案经过逐格验算：

```
 2  [2]  1   3
 1   3   2   4
 3   4  [1]  1
 4   1   3   2
```

第 1 行两个 2 去其一（涂 `(1,2)`），第 3 行两个 1 去其一（涂 `(3,3)`），
行列均无重复、黑格不相邻、14 个白格四连通。

## 已知局限（诚实版）

- 只做 4x4 / 5x5 小棋盘；更大尺寸回溯会变慢。
- 生成的谜题**不保证唯一解**，只保证可解；求解器返回第一个找到的解。
- 极少数"运气不好"的随机盘可能超出搜索预算，求解时如实报告无解（生成器会自动重试）。
- 无交互式涂黑，只有"看题 + 对答案"模式；需要 Python 3.10+。
